# Seguridad

En IEEStudio hay dos tipos de problema que reportar.

## Errores de cálculo

Un resultado de cálculo incorrecto es el problema más grave que puede tener
este proyecto: un conductor, interruptor o tubo mal dimensionado puede causar
un incendio. Si encuentras uno:

1. Abre un *issue* con el título «Error de cálculo», el archivo del proyecto o
   los datos del cálculo rápido, el resultado del programa, el resultado
   correcto y la cláusula o tabla de la norma que lo respalda.
2. Si el error puede afectar instalaciones ya calculadas, dilo en el *issue*
   para que la corrección se publique con aviso.

Cada error confirmado se convierte en un caso en `fixtures/engineering-cases/`
para que no vuelva a ocurrir.

## Vulnerabilidades del programa

Para fallas de seguridad del software (por ejemplo, un archivo de proyecto que
provoque la ejecución de código), usa la opción de reporte privado de
vulnerabilidades de GitHub en este repositorio en lugar de un *issue* público.

## Responsabilidad

IEEStudio no sustituye el criterio ni la firma de un profesional. Los
resultados deben revisarlos quien diseña y quien firma el proyecto.
